# E-Commerce App Launch — Project Management

## Project Overview
A simulation project where an e-commerce mobile app launch was planned 
and tracked using Project Management principles.

## Objective
To manage the app launch by following SDLC phases and Agile/Scrum 
methodology, along with building a Power BI dashboard to track progress.

## Tools Used
- Excel (Task Tracking)
- Power BI (Dashboard & Visualization)
- Agile/Scrum Methodology
- SDLC Framework

## Project Scope
- User Registration & Login
- Product Catalog & Search
- Shopping Cart & Checkout
- Payment Integration
- Order Tracking

## Approach
1. Created a Project Charter defining goal, scope, timeline, and team
2. Broke down development into 2 Agile Sprints with user stories
3. Built an Excel task tracker to monitor task status and ownership
4. Designed a Power BI dashboard to visualize sprint progress and delays
5. Handled a mid-sprint delay by evaluating trade-offs and adjusting scope

## Key Learnings
Practical exposure to project planning, sprint management, task tracking, 
and data-driven decision making using Power BI.
